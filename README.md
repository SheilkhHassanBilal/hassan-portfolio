# 🚀 Personal Portfolio Website - Hassan Bilal

Welcome to the official repository of my personal portfolio website! This project is crafted to showcase my professional background, technical systems, and projects.

## 🛠️ Built With

* **Framework:** [Next.js](https://nextjs.org/) (React)
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion & GSAP
* **Icons:** Lucide React

## 📂 Features

* **Interactive UI/Glow Effects:** Modern dark-mode glassmorphism design.
* **Project Showcase:** Highlights complex systems, automation workflows, and applications.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
